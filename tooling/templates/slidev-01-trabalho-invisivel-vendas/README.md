# Tema do deck 01

Cópia do tema do deck 02 (`slidev-02-o-que-sobra-sem-llm`), mesma origem no Figma
"LLM - Newton" (`8OkijdnUIMwqZWaQNa9LUX`). Mesmo palestrante, mesmo evento: os dois decks
compartilham o visual de propósito.

É uma cópia e não um link porque o gerador sobrepõe `tooling/templates/slidev/` com
`tooling/templates/slidev-<slug>/` e não há mecanismo de herança entre temas de deck. Se um
dos dois divergir, divergem sozinhos — nada aqui é lido pelo outro.

Tabela de layouts e assets: ver o `README.md` do tema 02.

Para tirar a lagosta da capa deste deck, remova o `<img class="cover-mascote">` de
`layouts/cover.vue`.
